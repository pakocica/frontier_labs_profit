# Frontier-AI-lab competition — interactive explorer

An economic model of frontier-AI-lab competition — a leader charging a premium for its
lead against an open-source follower selling the same capability at cost — as a title
page, a short written introduction, a three-level ladder of the model, and an
interactive explorer of the calibration, the figures it produces, and the equations
behind them.

**Live app:** https://pkocourek.com/frontier_labs_profit/

This is a static single-page app: a Vite/React/TypeScript build with the whole model
compiled into the bundle. Nothing runs on a server, and there is no runtime download
beyond the page itself.

## Layout

- `index.html`, `assets/` — the built app. Generated by `npm run build` in the research
  repository's `web/` package and committed here verbatim; `assets/` filenames are
  content-hashed, so the directory is replaced wholesale on every deploy.
- `model_note.pdf` — the written model note, shipped with every deploy so the public
  write-up always matches the deployed app.
- `mobile.html`, `tour.{js,css}` — the guided introduction, a slideable deck the app's
  masthead links to.
- `.nojekyll` — Pages serves this tree verbatim.

This repository only hosts the deployable snapshot; the app is developed in the
(private) research repository and pushed here by its `deploy/sync.sh`. Edits made
directly here will be overwritten by the next deploy.

Before 2026-08-05 the site was an [stlite](https://github.com/whitphx/stlite) build —
the Streamlit research widget running in the browser under Pyodide, with a boot overlay
covering the ~30–60 s WebAssembly download. That version remains in this repository's
git history.
